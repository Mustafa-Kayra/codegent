# Codegent - AI-Powered Coding Platform

🔷 **The best AI for coding** - A comprehensive AI-assisted development platform with 33 AI models and 20 language support.

## 🌟 Features

- **33 AI Models** - GPT-5.1, Claude Opus 4.5, Gemini 3, Grok 3, DeepSeek R1, and more
- **20 Languages** - Full internationalization support
- **Monaco Editor** - Professional code editing with 40+ language support
- **MCP Protocol** - Model Context Protocol for AI tool integration
- **Side by Side Comparison** - Compare responses from different AI models
- **"Try with another model"** - Regenerate any response with a different model
- **Dark Theme** - Beautiful, modern dark interface

## 📁 Project Structure

## 🚀 Getting Started

### Web Application

1. Open `app/index.html` in a browser
2. Click "Login with Puter" to authenticate
3. Start coding with AI assistance!

[Live Demo](https://codegent.puter.site)

### VS Code Extension

```bash
cd extension
npm install
npm run compile
# Then press F5 in VS Code to run
```
